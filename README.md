# My Stack
This is my realisation of one of the most widespread data sructure - stack.

This kind of structures works by FIFO (First In First Out) principle.

>The objective of the task is to attempt to create bullet proof data structure which would be able to protect user data from destortion.

To do so we used first level of protection which has a unique name - Сanary. (Miners would take the birds with themselves for their security: Once birds fell dead - that meant that methane was nearby)

Another level is to check hash and calculate new one every time any action is performed.

In this project both levels are designed. If something happens to your data, program will stop almost immediately and dump information about arised problem.
